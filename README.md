# Kwai Chung Gym Map

A small web tool for comparing gym locations and listed monthly fees around Brim Youth in Kwai Chung, Hong Kong.

**[Open the map](https://renyuqi-kiki.github.io/kwai-chung-gym-map/)** · [Author](https://github.com/Renyuqi-kiki)

## Contents

- `index.html` - the map and comparison interface.
- `.github/` - the GitHub Pages deployment workflow.

## Use

Open the hosted map or open `index.html` locally. Listed fees are reference information and may change; confirm current terms with the gym.

## 项目说明

葵涌 Brim Youth 周边健身房地图与月费对比。此项目属于生活工具，与研究项目分开展示。
